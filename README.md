#  Gokul's Portfolio Website

This is a responsive personal portfolio website built using HTML, CSS, and JavaScript. It introduces **Gokul Rajan** as a Web Developer and Electrical Engineer, showcasing his skills, projects, resume, and social media presence.

---

##  Features

-  Modern and responsive layout
-  Custom styling with Google Fonts (`Roboto`)
-  Dynamic greeting based on time of day
-  Smooth scrolling navigation
-  Skills showcase with icons
-  Social media links
-  Portfolio image section
